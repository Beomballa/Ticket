# 화면 간격과 규칙 점검

2026-09-20, 실제 로컬 화면과 CSS 계산값 기준.

## 화면별 결과

| 단계 | 화면 | 발견과 반영 | 결과 |
|---|---|---|---|
| 1 | 공연 홈 | 헤더 로고와 본문 시작선이 약 17px 불일치. 공통 폭과 gutter 계산 적용 | 1280px에서 헤더·본문·푸터 x=66.5px, 768px에서 헤더·본문 x=24px |

기본 20개 상투적 패턴 중 로그인 안내에서 의미 없는 기호 장식을 확인해 제거했다. 나머지는 이번 수정의 근거로 사용하지 않았다. 브랜드 Primary `#075E46`과 Secondary `#E8FFF2`, 포스터, 기존 예매 기능은 유지한다.

## 검증

- 320·390px 모바일, 768px 태블릿, 1280px 데스크톱에서 검토한 화면에 가로 넘침 없음.
- 로그인 창 Shift+Tab 순환, Escape 닫기, 포커스 외곽선 확인.
- 검색어 입력 후 검색 결과, 전체 공연 복귀, 상세 열기, 관람 회차 변경 확인.
- 입력 경계 `#81938A`: 흰색 대비 3.24:1, Canvas 대비 3.01:1. 기존 브랜드 텍스트 색상 유지.
- 프론트엔드 기존 테스트 21개 통과, 최종 TypeScript·Vite 프로덕션 빌드 통과. 스타일 변경 전용 테스트는 추가하지 않음.

## 확인 범위

관리자 인증 후 운영 테이블과 로그인 후 예약 목록은 이번 브라우저 점검에서 열지 않았다. 이 영역에는 공통 입력 규격과 카드 토큰이 적용되며, 예약 상세 모바일 상단 여백 수정은 CSS 우선순위 점검에 근거한다. 실결제, 예약 생성·취소, 전체 스크린리더 검증은 수행하지 않았다.

수정 전후 화면은 로컬 검증 폴더에 보관하며 Git에 포함하지 않는다. 간격·입력·모서리 기준은 `design-system.md`에 반영했다. 기존 정책의 사업자 정보 입력 필요 항목은 이번 수정 범위 밖이다.
