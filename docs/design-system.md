# StagePass 디자인 시스템

## 브랜드 팔레트

| 역할 | 색상 | 사용 범위 |
|---|---|---|
| Primary | `#075E46` | 주요 버튼, 활성 탭, 링크 강조, 포커스, 재고 게이지 |
| Primary Strong | `#044735` | 주요 버튼 hover와 강한 브랜드 텍스트 |
| Primary Soft | `#E8FFF2` | 예약·결제·대기열처럼 브랜드 맥락의 안내 Surface |
| Canvas | `#F5F7F6` | 전체 페이지 배경 |
| Surface | `#FFFFFF` | 카드, 입력, Drawer, Modal |
| Surface Subtle | `#F8FAF9` | 표 헤더, 하위 그룹, 보조 hover |
| Ink | `#1F2925` | 제목과 본문 핵심 정보 |
| Muted | `#5C6963` | 설명, 메타데이터, 보조 레이블 |
| Line | `#D8E2DD` | 카드, 입력, 표의 경계 |

Primary와 Primary Soft는 임의의 유사색으로 대체하지 않는다. 한 화면의 주요 행동은 Primary로 표시하고, 같은 행동 그룹에서 여러 Primary 버튼이 경쟁하지 않게 한다. Primary Soft 위에는 Primary 또는 Ink 텍스트를 사용한다.

## 상태 색상

브랜드색과 상태색은 역할을 분리한다. 성공은 `#0B7661`, 주의는 `#9A5B00`, 오류는 `#B3261E`, 처리 중 정보는 `#365FA8`을 사용한다. 상태색은 Badge, 오류·주의 안내와 운영 상태에만 사용하고 장식에는 사용하지 않는다.

각 상태는 진한 텍스트와 연한 배경을 함께 사용하며 색상만으로 의미를 전달하지 않는다. 화면에는 상태 이름이나 설명을 항상 함께 표시한다.

## Surface와 깊이

기본 콘텐츠는 흰색 Surface와 1px Line으로 구분한다. 예약 진행이나 선택 상태는 Primary Soft를 사용한다. 그림자는 Modal, Drawer, Toast처럼 실제로 화면 위에 뜨는 요소에만 사용한다. 카드 계층을 표현하기 위해 그림자를 반복해서 추가하지 않는다.

## 입력과 버튼

Input과 Select는 흰색 배경, 1px `--control-line: #81938A`, 8px 모서리, 최소 44px 높이, 16px 입력 글자를 사용한다. 입력 경계는 카드 구분선보다 진하게 표현하며 흰색 대비 3.24:1, Canvas 대비 3.01:1이다. 키보드 포커스는 Primary 3px outline으로 표시한다. 주요 버튼은 Primary 배경과 흰색 텍스트를 사용하며 최소 높이는 44px이다. 공연 전환 버튼도 모바일에서 최소 44×44px을 유지한다.

## 정렬과 간격

헤더·본문·푸터는 `--content-width: 1180px` 안의 같은 시작선을 사용한다. `--page-gutter`는 데스크톱 24px, 680px 이하 모바일 16px이다. 헤더 계산에는 스크롤바를 포함하는 `100vw` 대신 사용 가능한 컨테이너 폭을 사용한다.

폼의 레이블과 입력 사이는 `--space-field: 8px`, 입력 그룹 사이는 `--space-group: 16px`, 일반 패널과 제목 그룹은 `--space-panel: 24px`를 기준으로 한다. 콘텐츠에 따른 기존 포스터·히어로 여백은 별도로 유지한다. 카드 모서리는 12px, 컨트롤은 8px, 인증 모달은 16px이다.

모바일 인증 모달의 좌우 여백은 20px, 제목은 26px이다. 공연 상세 제목은 23px이며 공통 Drawer 제목 규칙이 덮지 않도록 한다. 예약 상세의 상단 여백은 모바일에서도 80px을 유지해 닫기 버튼 공간을 확보한다. 로그인 필요 안내는 바깥 margin과 안쪽 padding으로 여백을 중복하지 않는다.

## 대비 기준

흰색 위 Primary는 7.78:1, Primary Soft 위 Primary는 7.42:1, 흰색 위 Muted는 5.74:1이다. 새로운 색상을 추가할 때 일반 텍스트는 최소 4.5:1, 큰 텍스트와 UI 경계는 최소 3:1을 유지한다.

## 기준 화면과 확장 순서

공연 탐색 메인(`/`)을 첫 기준 화면으로 사용한다. NOL의 콘텐츠 그룹 구분을 참고하되 브랜드, 이미지, 코드와 상품 정보를 복제하지 않는다. 다른 화면을 동시에 독립적으로 디자인하지 않고 메인 검증 후 상세·예약 화면에 공통 기준을 적용한다.

`frontend/src/styles.css`는 브랜드 토큰, 입력, 버튼, 포커스 및 공통 요소를 담당한다. `frontend/src/catalog-layout.css`는 메인의 폭, 섹션 간격, 추천 공연 구조와 반응형 그리드를 담당한다. 새 화면은 기존 공통 토큰을 먼저 사용하고, 공연 전용 레이아웃을 무작정 복사하거나 전역 선택자를 덮어쓰지 않는다.

| 기준 | 데스크톱 | 980px 이하 | 680px 이하 |
|---|---|---|---|
| 독립 섹션 간격 | 56px | 56px | 40px |
| 포스터 열 수 | 4 | 3 | 2 |
| 카드 열 / 행 간격 | 24 / 36px | 20 / 30px | 14 / 28px |
| 추천 영역 | 설명과 포스터 2열 | 설명과 포스터 2열 | 제목·포스터 위, 전체 폭 설명·CTA 아래 |

카드 메타정보는 4px, 아티스트와 장소 그룹은 8px, 가격 앞은 16px 간격을 사용한다. 섹션 제목의 불필요한 상단 margin은 제거한다. 최소 터치 크기 44px과 포커스는 유지한다. 추천 높이는 고정하지 않으며 긴 제목에도 내용이 잘리지 않게 한다.

2026-09-21 검증: 실제 API 데이터로 데스크톱 1280px, 모바일 390px·320px 확인. 추천 영역의 데스크톱 높이는 샘플 공연 기준 약 395px(기존 484px). 모바일 320px·390px에서 문서 가로 넘침 없음. 재즈 검색 2개, 팬미팅 필터 2개, 초기화 8개, 상세 회차 변경, Escape 닫기, 검색 버튼의 키보드 포커스, 약관·개인정보 링크 확인. 결제·예약 생성은 이번 화면 검증에서 실행하지 않았다.
