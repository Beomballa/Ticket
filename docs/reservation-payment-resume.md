# 내 예약 결제 이어하기

2026-09-19, 로컬 PostgreSQL/Redis 및 React 개발 서버 기준.

## 확인한 문제와 변경

| 확인한 문제 | 변경 |
|---|---|
| 공연 창을 닫으면 선점한 예약의 결제를 이어갈 수 없음 | 내 예약 상세에 모의 결제 이어하기 추가 |
| 내 예약에서 새로고침하면 공연 목록으로 돌아감 | `/reservations`와 `/admin` 경로를 화면 상태에 연결 |
| 결제 기한이 고정 시각으로만 표시됨 | 서버 만료 시각 기준 초 단위 남은 시간과 만료 안내 표시 |
| 예약 상세의 키보드 이동·닫기 동작이 다른 창과 다름 | 기존 공통 대화상자 포커스 처리 적용 |
| 상태 갱신 중 목록이 사라져 닫은 뒤 포커스를 잃음 | 기존 목록 DOM 유지, 카드가 사라지면 제목으로 복귀 |

기존 20개 디자인 진단 항목에서 새로 수정할 장식적 문제는 확인하지 않았다. 기존 색상·타이포그래피·반응형 구조를 유지하고 예약 행동과 상태 안내만 보완했다.

## 동작 경계

결제 대기 상태이며 남은 시간이 있는 예약만 결제할 수 있다. 브라우저 시계는 안내용이며 서버가 최종 만료·결제 가능 여부를 결정한다. 같은 상세 창의 재시도는 동일한 멱등 키를 사용한다. 새로 열면 새 키가 생성되며 예약 상태를 다시 읽는다.

결제 성공 응답의 상태는 목록 재조회와 별도로 즉시 반영한다. 목록 조회 실패 때문에 이미 성공한 결제를 실패로 안내하지 않는다. 최신 상태 확인은 서버의 상세와 목록을 다시 조회한다. 백엔드 API 계약, DB 스키마와 기존 취소·재고 반환 처리는 변경하지 않았다.

## 검증 결과

- 프론트엔드 테스트 총 21개 통과. 만료 직전·정각·이후, 결제 불가 상태, 잘못된 기한, 경로 복원, 재시도 멱등 키를 포함한다.
- TypeScript 및 Vite 프로덕션 빌드 통과.
- 실제 UI에서 선점 → 공연 창 닫기 → 내 예약 새로고침 → 모의 결제 이어하기 → 확정 → 취소 확인.
- 별도 테스트 예약의 만료 시각만 단축해 상세 조회 시 시간 만료 상태와 결제 버튼 제거를 확인. 최신 상태 확인으로 목록도 만료 상태로 갱신됐다. 브라우저의 카운트다운 0초 전환 순간은 직접 관찰하지 않았으며 경계값은 단위 테스트로 검증했다.
- 1280px 데스크톱과 390px 모바일에서 결제 대기 상세, 320px 모바일에서 만료 상세 확인. 가로 넘침 없음.
- Shift+Tab 순환, Escape 닫기, 상태 갱신 후 원래 예약 카드로 포커스 복귀 확인. 브라우저 뒤로·앞으로 이동의 경로 복원 확인.
- 주요 버튼 및 새 안내 영역의 텍스트 대비를 기존 색상 토큰으로 확인. 타이머는 매초 스크린리더 알림을 보내지 않는다. 전체 접근성 인증이나 스크린리더 전수 검증은 아니다.

## 유지 범위와 남은 확인

공연 검색·회차 선택·인증·대기열·운영 콘솔·정책 링크를 유지했다. 대기열 부하와 운영 콘솔 전체 기능은 이번 변경에서 재검증하지 않았다. 인증 만료 안내 분기는 구현했지만 실제 세션 만료 상황의 브라우저 검증은 수행하지 않았다.

실제 PG 결제가 아닌 모의 결제이며 실제 금액은 청구되지 않는다. 기존 약관·개인정보처리방침의 운영 사업자 입력 필요 항목은 그대로 유지한다. 검증 계정 입력값, 토큰, 개인 환경 경로와 화면 캡처는 커밋하지 않는다.
