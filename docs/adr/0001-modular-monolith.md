# ADR-0001: 모듈형 모놀리스로 시작한다

- 상태: 승인
- 결정일: 2026-09-09

## 배경

포트폴리오의 핵심은 분산 시스템의 개수보다 예약 정합성, 트랜잭션, 멱등성, 조회 성능과 장애 복구를 검증 가능한 형태로 보여주는 것이다.

## 결정

하나의 Spring Boot 애플리케이션과 PostgreSQL로 시작한다. 패키지는 `member`, `catalog`, `inventory`, `reservation`, `payment`, `notification`, `admin`, `support` 모듈 경계를 따른다. Redis는 캐시와 속도 제한 같은 보조 역할에만 사용한다.

## 결과

- 로컬 트랜잭션으로 핵심 정합성을 먼저 완성할 수 있다.
- 배포와 장애 재현 환경이 단순해진다.
- 모듈 사이의 직접 의존은 코드 리뷰와 테스트로 관리해야 한다.
- 독립 확장이 필요한 경계와 측정 근거가 생긴 뒤에만 서비스 분리를 검토한다.
