# StagePass 화면 디자인 기준

Apple 참고 자료의 중립적인 표면, 콘텐츠 중심 위계, 절제된 효과를 참고한다. Apple의 브랜드 색이나 전용 폰트 자산을 복제하지 않는다.

## 색상과 표면

- 주요 행동: #176B87. 호버: #10516A. 보조 표면: #EAF3F6.
- 배경: #F4F6F7. 내용 표면: #FFFFFF. 본문: #20272C. 보조 글: #5D6870.
- 색상은 styles.css의 토큰을 사용한다. 성공·경고·실패 색은 실제 상태에만 사용한다.
- 목록은 경계선으로 구분하고, 그림자는 겹쳐 열리는 창에 사용한다.
- 기본 컨테이너 모서리는 12px, 조작 요소는 8px이다.

## 구성

- 홈은 검색·장르 탐색, 실제 DB에 등록된 주목할 공연, 포스터 목록 순서로 구성한다. NOL의 탐색 구조를 참고하되 로고·원본 공연 포스터·랭킹·판매 수치는 복제하지 않는다.
- 가상 공연 이미지는 생성 자산으로 제공하고 DEMO 표시를 유지한다. 대응 이미지가 없는 사용자 등록 공연은 정직하게 '포스터 준비 중'으로 표시한다.
- 판매 상태는 잔여 수량을 보장하지 않는다. 수량은 상세 API의 실제 값으로 표시한다.
- 목록은 데스크톱 4열, 태블릿 3열, 모바일 2열이다. 포스터 비율은 2:3으로 고정하고 제목 길이가 달라도 이미지 상단을 맞춘다.
- 목록의 날짜·공연장·최저 가격은 API의 overview를 사용한다. 판매 시작일과 공연 날짜를 혼동하지 않으며 판매 상태를 매진 여부로 표현하지 않는다.
- 주목할 공연은 자동 재생하지 않는다. 버튼으로 선택하고, 색은 포스터를 받쳐주는 절제된 중립 표면만 사용한다.
- 상세에서는 회차를 먼저 고른다. 오픈 예정·판매 종료·매진은 예약 버튼을 비활성화하고 실제 예약 가능 여부는 서버가 최종 검증한다.
- 상세와 로그인은 Escape 닫기, Tab 포커스 제한, 닫은 뒤 기존 위치 복귀를 지원한다.
- 최대 내용 폭은 1180px, 기본 좌우 여백은 24px, 모바일은 16px이다.
- 제목·본문·보조 정보의 크기와 간격을 구분하고 억지로 카드 수를 맞추지 않는다.

## 검증

- 변경 전에 실제 화면에서 확인한 문제와 수정 방향을 제시한다.
- 320px, 390px, 768px, 1440px에서 가로 넘침, 검색 버튼 줄바꿈, 상세와 로그인 창을 확인한다.
- 키보드 포커스, 링크, 텍스트 대비와 동작 감소 설정을 유지한다.
- API 계약·예약 처리·기존 데이터는 시각 변경 때문에 바꾸지 않는다.
- 약관과 개인정보 문서의 미확정 사업 정보는 임의로 채우지 않는다.
